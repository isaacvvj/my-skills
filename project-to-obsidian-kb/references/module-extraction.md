# 模板候选提取边界

扫描器只在领域索引中聚合模块候选，帮助 AI 从原工程头文件、实现、调用方、构建配置和硬件资料开始阅读；不要默认创建一模块一笔记，也不要自动移动代码。

进入模板仓库前必须：

1. 明确公共 API、输入输出、单位、时序、错误与安全状态；
2. 隔离全局变量、项目状态机和项目专用耦合；
3. 明确 HAL/BSP/SDK、PinMux、DMA、中断、任务、链接和构建依赖；
4. 复制到新的模板候选工程后完成独立构建；
5. 硬件相关模块完成目标板验证；
6. 在对应知识库模板笔记中回写 `repo_relative_path`、构建命令、验证状态和可信等级。

`main.*`、顶层调度、自动生成文件、厂商 SDK、启动文件、链接脚本、`.ioc`、`.syscfg` 和 IDE 配置默认只记录边界，不自动提取。
